# JetBrainsMono Nerd Font Mono

Unmodified Regular and Bold files from https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/JetBrainsMono/Ligatures .

Font upstream: https://github.com/JetBrains/JetBrainsMono . SIL OFL 1.1 is retained in OFL.txt. Nerd Fonts patch/icon licensing notices are retained in NERD-FONTS-LICENSE.txt. The font files are served locally, without OS installation or a third-party runtime font request.
